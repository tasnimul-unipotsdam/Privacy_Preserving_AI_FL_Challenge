# Recorded validation evidence


| File | Meaning |
|---|---|
| `validation_report.json` | Unmodified official evaluator, 30 public cases |
| `docker_report.json` | Same evaluator applied to offline Linux container predictions |
| `experiment_summary.json` | Training-only holdout, seeds, site comparisons and convergence |
| `privacy_summary.json` | Exact prototype claim, limitations and measured secure/plain comparison |
| `model_comparison.json` | Optional labelled public validation comparison, including calibration bins |
| `verification.json` | Environment, checks, image size and cross-platform agreement |
